# Project Brief & Product Context

## 1. Misión del Proyecto
Construir software de alta fidelidad, escalabilidad y confiabilidad industrial mediante la orquestación agéntica de 11 roles especializados bajo estándares de ingeniería de software de clase mundial.

## 2. Objetivos de Negocio
- Adquisición y monetización determinista.
- Cero regresiones semánticas ni deuda técnica acumulada.
- Tiempos de ciclo de desarrollo reducidos al mínimo sin sacrificar rigor arquitectónico.
