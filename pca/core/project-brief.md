# Project Brief & Product Context

## 1. Misión del Proyecto
Construir software de alta fidelidad, escalabilidad y confiabilidad industrial mediante la orquestación agéntica de 5 especialistas hiper-enfocados bajo principios de POO, SOLID, Arquitectura Hexagonal y C4 en Mermaid.

## 2. Objetivos de Negocio
- Adquisición y monetización determinista sin sobreingeniería.
- Cero regresiones semánticas ni deuda técnica acumulada (garantía Zero Human Code Review).
- Tiempos de ciclo de desarrollo reducidos al mínimo mediante el ciclo SDD de 4 pasos.
